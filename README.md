## 🛒 Overview
This **pet products e-commerce website**, built with HTML, CSS using Flexbox for a responsive layout, and vanilla JavaScript for dynamic features like item filtering, integrates FormSpree for form submissions. The result is a fast, modern shopping experience for pet lovers.

## 🚀 Technologies Used

| Technology	| Purpose                                                    	|
|---------------|----------------------------------------------------------------|
| **HTML**  	| 🧱 Structures the content and layout of the site.          	|
| **CSS (Flexbox)** | 🎨 Creates a responsive and clean visual layout.     	|
| **JavaScript**| ⚙️ Powers dynamic interactions like filtering and modals. 	|
| **FormSpree** | 📬 Handles form submissions securely and simply.           	|

<br>

## 📑 Key Features

- 🐶 **Product Filtering**: Filter items by category using JavaScript.
- 🖼️ **Photo Gallery**: Organized layout for browsing product images.
- 🔍 **Modal Viewer**: Click to enlarge images in a sleek popup.
- ❤️ **Double-Click Liking**: Like photos with a quick double-click.
- 📱 **Responsive Design**: Works beautifully on desktop, tablet, and mobile.
