This pet products e-commerce website, built with HTML, CSS using Flexbox for a responsive layout, and vanilla JavaScript for dynamic features like item filtering and smooth scrolling, integrates FormSpree for form submissions to deliver a seamless and engaging shopping experience.

## 🚀 Technologies Used 🚀

- **HTML**: Structures the content and layout of the website.
- **CSS (Flexbox)**:  Creates a responsive, flexible layout.
- **JavaScript**: Enables interactivity like filtering and smooth scrolling.
- **FormSpree**: Handles contact order form submissions easily.

## 📑 Key Features 📑

- **Product Filtering**: Sort products by category using JavaScript.
- **Photo Gallery**: Browse product images in an organized layout.
- **Modal Viewer**: View enlarged images in a popup overlay.
- **Double-Click Liking**: Like photos instantly with double-click action.
- **Responsive Design**: Optimized for all devices.
